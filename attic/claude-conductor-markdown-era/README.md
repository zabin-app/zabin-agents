# Claude conductor, markdown era

Preserved copy of the Claude Code user-level `conductor` skill as it stood before the pipeline moved to Zabin MCP — a conductor whose ledger was Markdown (`PLAN.md`, `TASKS.md`, `REVIEW.md`, `ACTION_ITEMS.md`, per-task files) with its planning, review, and action-item templates — retired on 2026-08-22 when the portable [`skills/conductor`](../../skills/conductor/SKILL.md) became the single conductor.

Historical reference only: nothing installs, renders, or validates from this directory, and its instructions are superseded by the portable skill and its [Claude Code adapter notes](../../skills/conductor/references/claude.md).
